# Adventure-Works-Data-Analytics
Data analytics project using Excel, SQL, Tableau, and Power BI based on the Adventure Works dataset.
## Project Overview

This project focuses on analyzing the Adventure Works business dataset to identify sales, profit, production cost, customer, product, and regional performance.

The project includes data preparation, analysis, visualization, and dashboard development using Excel, SQL, Tableau, and Power BI.

## Tools & Technologies

- Microsoft Excel
- SQL
- Tableau
- Power BI

## Key Analysis

- Sales and profit analysis
- Production cost analysis
- Customer performance
- Product performance
- Regional performance
- Year-wise and month-wise sales analysis
- KPI and dashboard development

## Key Results

- Total Sales: ₹29.36M
- Total Profit: ₹12.08M
- Profit Margin: 41.15%
- Orders: Approximately 60,000
